# Étude descriptive sur données d'enquête de l'European Social Survey (ESS)

Réalisation d'une étude descriptive sur données d’enquête provenant de l’European Social Survey (ESS). L’European Social Survey (ESS) est une enquête européenne de référence en sciences sociales réalisée tous les
deux ans pour mesurer les opinions, valeurs et comportements des habitants de différents pays. 

Il s’agit de rendre un rapport d’une longueur entre 5 et 10 pages, en explorant la thématique proposée à l’aide du langage R.

Pour utiliser le code R, il faut préalablement télecharger les données, puis adapter le nom de chemin, plus de détails dans le fichier "description_projet".
